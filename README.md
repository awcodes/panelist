# Panelist

A Filament plugin that turns a resource's list page into a master-detail editor, in the style of Gmail, Notion or Linear: the record list on the left, the selected record's form on the right.

## Installation

```bash
composer require awcodes/panelist
```

Panelist's stylesheet and views need to be added to your Filament theme. See [Installation](https://docs.aw.codes/panelist/1.x/installation) for that step, then [Usage](https://docs.aw.codes/panelist/1.x/usage) to give a resource a Panelist page.
